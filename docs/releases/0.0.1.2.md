Merhaba, ben Taylan. Bu bir düzeltme sürümü. Talvora'nın bilgisayardaki gizli anahtarlara nasıl davrandığını netleştiriyor, ajanların çalıştırdığı komutların çıktısını eksiksiz görmesini sağlıyor ve çalışma günlüğünü biraz daha doğru konuşturuyor.

## Düzeltmeler

- **Gizli anahtarlar yanlışlıkla sohbete düşmüyor.** Talvora'nın gizli anahtarlar için ayırdığı klasör (`C:\ProgramData\Talvora\Secrets`) ve Context7 anahtarı artık dosya araçlarıyla okunmuyor, aramalarda da görünmüyor. Bu klasörü ya da onu içeren bir üst klasörü silmek, taşımak, başka yere kopyalamak veya arşivlemek de reddediliyor; bunu deneyen ajan Türkçe bir açıklama alıyor. Bu yalnızca kazalara karşı bir önlem, olağan işlerin hiçbirini engellemiyor.
- **Komut çıktısı eksiksiz geliyor.** Ajanın senin kullanıcınla çalıştırdığı komutların çıktısı artık olduğu gibi dönüyor. Önceki sürüm sırra benzeyen bölümleri "[REDACTED]" ile gizliyordu; bu bazen sıradan satırları da yakalıyor, ajanın işini zorlaştırıyordu. Kayıt dosyalarında ve ekrandaki çalışma günlüğünde sırlar eskisi gibi gizleniyor. Bu gizleme artık Context7 anahtarlarını ve komut satırında `--token` gibi seçeneklerle verilen değerleri de kapsıyor.
- **Kurulum adımı sonuna kadar izleniyor.** Talvora'yı güncelleyen bir ajan çıktıyı kısa istese bile çalışma günlüğündeki adım artık "Yeni sürüm çalışıyor" ile kapanıyor. Önceden "doğrulama bekleniyor"da kalabiliyordu.
- **Rust, uv ve Python testleri test olarak görünüyor.** `cargo test`, `uv run pytest` ya da `python -m unittest` gibi çalıştırmalar çalışma günlüğünde "Testler geçti" veya "Testler başarısız" diye, `cargo build` da "Derleme başarılı" diye görünüyor. Diğer cargo ve uv komutları da ne olduğunu söylüyor, örneğin "Cargo komutu tamamlandı · fmt".

## Bilinen sorunlar

- Kurulum dosyası henüz imzalı değil, bu yüzden Windows ilk açılışta bir uyarı gösterebilir. **Ek bilgi**'ye, sonra **Yine de çalıştır**'a basman yeterli. İstersen önce dosyanın SHA-256 değerini bu sayfadaki `SHA256SUMS.txt` ile karşılaştırabilirsin.

---

**In English:** A fix release. Talvora's folder for secrets (`C:\ProgramData\Talvora\Secrets`) and the Context7 key can no longer be read or found by its file tools, and deleting, moving, copying or archiving that folder, or a folder that contains it, is refused, so an agent cannot leak them into a chat by accident. Commands an agent runs as the signed-in user now return their full output instead of masking anything that looked like a secret, which sometimes hid ordinary lines; logs and the on-screen work log stay masked and now also cover Context7 keys and values passed with options such as `--token`. A self-update step in the work log now ends with "Yeni sürüm çalışıyor" even when the agent asked for short output, and Rust (cargo), uv and Python test runs appear as tests. The installer is still unsigned, so compare it with `SHA256SUMS.txt`.
