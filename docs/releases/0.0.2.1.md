Merhaba, ben Taylan. Bu küçük sürümü bir güvenlik güncellemesi için beklemeden çıkarıyorum. Yanında, bir adım başarısız olduğunda kartın gerçekten ne olduğunu anlatması geliyor.

## Düzeltmeler

- **Yapısal kod düzenleme motoru güvenlik sürümünde.** Talvora'nın içinde gelen ast-grep, güvenlik uyarısı yayımlanan eski sürümden 0.51.3'e geçti.
- **Başarısız adım nedenini söylüyor.** Masaüstü kartı artık her hatada aynı genel cümleyi yazmıyor: bir komut hangi çıkış koduyla bittiyse, dosya bulunamadıysa ya da değişiklik dosyanın güncel hâliyle eşleşmediyse bunu sade Türkçeyle söylüyor; yapılabilecek bir sonraki adım varsa onu da yazıyor.
- **Git, kendi yok sayma kuralların ile çalışıyor.** Talvora'nın çalıştırdığı git işlemleri, oturum açmış kullanıcının genel `.gitignore` dosyasını da dikkate alıyor; böylece kendi bilgisayarında görmediğin dosyalar ajanın gördüğü listede de çıkmıyor.

## Bilinen sorunlar

- Deposunun kendi ayarında ayrı bir yok sayma dosyası (`core.excludesFile`) tanımlayan depolarda, Talvora'nın git işlemleri o dosya yerine kullanıcının genel dosyasını okuyor. Bir sonraki sürümde düzelecek.
- Kurulum dosyası henüz imzalı değil, bu yüzden Windows ilk açılışta bir uyarı gösterebilir. **Ek bilgi**'ye, sonra **Yine de çalıştır**'a basman yeterli. İstersen önce dosyanın SHA-256 değerini bu sayfadaki `SHA256SUMS.txt` ile karşılaştırabilirsin.

---

**In English:** A security update: the bundled structural-edit engine (ast-grep) moves to 0.51.3, out of an advisory's range. A failed step on the desktop card now states its real reason (the exit code, a missing file, a stale edit) and the next step where there is one. Git run by Talvora honours the signed-in user's global ignore file. Known issue: a repository that sets its own `core.excludesFile` gets the user's global file instead; fixed in the next release. The installer is still unsigned, so compare it with `SHA256SUMS.txt`.
