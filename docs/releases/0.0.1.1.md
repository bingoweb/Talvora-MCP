Merhaba, ben Taylan. Bu küçük bir düzeltme sürümü. En önemli parçası kurulum dosyasındaki bir güvenlik düzeltmesi, o yüzden beklemeden yayımlıyorum.

## Düzeltmeler

- **Kurulumda güvenlik düzeltmesi.** Bilgisayarında PowerShell 7 yoksa kurulum onu Microsoft'un resmi paketinden kurar. Bu paketi açan Windows kurucusunu (`msiexec.exe`) artık doğrudan Windows'un sistem klasöründen çalıştırıyor. Önceki sürüm onu yalnızca adıyla çağırıyordu; Windows da böyle bir adı önce kurulum dosyasının durduğu klasörde, çoğu zaman İndirilenler'de arar. Oraya aynı adla bırakılmış bir dosya, yönetici yetkisiyle çalışabilirdi. Bu yalnızca kurulum sırasında ve PowerShell 7 eksikken önemliydi; kurulu bir Talvora'yı etkilemiyor.
- **Çalışma günlüğü kendini tekrar etmiyor.** "Kanıtlar" bölümü artık yalnızca adımın altında yazmayan bilgiyi gösteriyor. Bir commit'in özeti üç kez yazılmıyor, komut da ayrı ve soluk bir satırda duruyor.
- **Adımlar bitmiş cümlelerle okunuyor.** Ajanın oturum başında proje talimatlarını alması, GitHub komutları, bağlantı denetimi, kasaya not yazma ve proje incelemesi artık "Proje talimatları alındı", "Kasaya not yazıldı" gibi görünüyor.
- **Türkçe düzeltmeleri.** Tepsi menüsünde "Kontrol Merkezi'ni aç", "Gitea'yı aç" ve "Gitea'yı yeniden başlat" yazıyor; yerel servis menüde ve bildirimlerde de Hizmetler sayfasındaki gibi "Talvora Çekirdeği" adıyla geçiyor. Windows'un servisler listesindeki açıklama da artık Türkçe.

## Bilinen sorunlar

- Kurulum dosyası henüz imzalı değil, bu yüzden Windows ilk açılışta bir uyarı gösterebilir. **Ek bilgi**'ye, sonra **Yine de çalıştır**'a basman yeterli. İstersen önce dosyanın SHA-256 değerini bu sayfadaki `SHA256SUMS.txt` ile karşılaştırabilirsin.

---

**In English:** A small fix release, published right away because of an installer security fix. When PowerShell 7 is missing, the installer now starts Windows Installer (`msiexec.exe`) from the Windows system folder instead of by name, so a file with that name left next to the installer, for example in Downloads, can no longer run with administrator rights. It only mattered during installation, not for an installed Talvora. The work log's evidence section no longer repeats the same fact, agent steps read as finished sentences, and the tray menu, notifications and Windows service description are now proper Turkish. The installer is still unsigned, so compare it with `SHA256SUMS.txt`.
